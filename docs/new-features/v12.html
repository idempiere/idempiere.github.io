New features in iDempiere 12

Features integrated in iDempiere v12.

📄️All Quantities in Storage Per Product

When you want to know how many items of a product you have on hand, you can use the Storage Per Product report.

📄️Exclude Freight Charges from Payment Discount

To improve the accuracy of payment discounts, a new flag IsExcludedFromDiscount was introduced on the Charge (C_Charge) table.

📄️FEATURE: Fast entity type identification

Entity type identification can be activated in the User preference window by checking the 'Show Technical Information on Help' flag

📄️Multiple Payments against statement line by Payment Batch

Tag Payment Into Batch to Bank Statement Line and Document Workflow Support for Payment Into Batch

📄️New Fields in Country

New Fields in Country: a New Feature in iDempiere 12.

📄️Prepay Order Configurable Shipment and Invoicing

Prepay Order Configurable Shipment and Invoicing: a New Feature in iDempiere 12.

📄️Reactivation of Invoices

Reactivation is configurable per Role and Document Type.

📄️Support UOM On Inventory Move

This new feature introduces the UOM and Qty Entered fields in Inventory Move Line.

📄️Unallocated Cash and Payment Selection Configurable Business Partner

Unallocated Cash and Payment Selection Configurable Business Partner: a New Feature in iDempiere 12.

📄️Virtual Column as Report Parameter

Virtual Column as Report Parameter: a New Feature in iDempiere 12.

📄️Add option to Disable "Insufficient Inventory" Popup

Add option to Disable "Insufficient Inventory" Popup: a New Feature in iDempiere 12.

📄️Enhance Print Invoices Process to Support Multi-Select Document Type Parameter

Enhance Print Invoices Process to Support Multi-Select Document Type Parameter: a New Feature in iDempiere 12.

📄️Context Variable HTML REPORT THEME

report.css path is configurable using system configuration named HTMLREPORTTHEME.

📄️Define HTML field at field level

Define HTML field at field level: a New Feature in iDempiere 12.

📄️Document Search Customisable Layout

Document Search Customisable Layout: a New Feature in iDempiere 12.

📄️Email Template Markdown Text

Implement markdown text support for email template

📄️Export Tree Definition

Before this change, it was only possible to export the main menu tree.

📄️Get image through url from attachment

Get image through url from attachment: a New Feature in iDempiere 12.

📄️ImageURL Fieldtype

ImageURL Fieldtype: a New Feature in iDempiere 12.

📄️Implement escape sequence for text with context variable

Implement escape sequence for text with context variable: a New Feature in iDempiere 12.

📄️IProcessParameterListener - add onInit method

IProcessParameterListener - add onInit method: a New Feature in iDempiere 12.

📄️Multiple SSO Provider Support

This enhancement introduces the ability to configure and support multiple Single Sign-On (SSO) providers in iDempiere.

📄️Status Line Widget Markdown And Scoped Style

Implement markdown and scoped style support for status line widget

📄️Support for Alternate DB Admin User

Normally there are fixed admin users for Oracle (SYSTEM) and for PostgreSQL (postgres).

📄️Theme Customization

Objective of the ticket is to allow minor variations on themes.

📄️Use System Configurator from css files

Objective of the ticket is to load dynamically some resources such as a background image for the login page.

📄️Validate Required Plugins

Validate Required Plugins: a New Feature in iDempiere 12.

📄️Development With Intellij

With the help of the Eclipse PDE Partial plugin, use IntelliJ for iDempiere development.

📄️Improve Password Hashing

Currently password hashing is using SHA-512 and salt is generated using SHA1PRNG random generator and 64 bytes.
