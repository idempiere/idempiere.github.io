New features in iDempiere 1.0

Features integrated in iDempiere v1.0.

📄️Accounting Viewer Improvements

Review accounting entries without interrupting your workflow. The Accounting Viewer now opens as a standalone window instead of a blocking popup.

📄️Allocate Payment To Charge

Allocate Payment To Charge: a New Feature in iDempiere 1.0.

📄️Configurable Copy Fields

Configurable Copy Fields: a New Feature in iDempiere 1.0.

📄️Confirm Document Void / Close

Closing and Voiding documents can be a dangerous not-reversible operation.

📄️Copy From Bank Statement

This new feature adds CopyFrom on Bank Statement.

📄️Inventory Cost Adjustment

A new window to allow the entering of cost adjustment for product.

📄️Improved Document Sequence

Improved Document Sequence: a New Feature in iDempiere 1.0.

📄️Dynamic Zoom

This enhancement allow the application to determine zoom window at runtime through the use of data driven SQL rule.

📄️Financial Report Enhancement

Financial Report Enhancement: a New Feature in iDempiere 1.0.

📄️Find Window

The history button was moved from toolbar to search window.

📄️Fixed Assets Stabilization

With the release 1.0 of iDempiere the Fixed Assets extension was fully integrated and a stabilization effort was contributed.

📄️GL Reconciliation

GL Reconciliation: a New Feature in iDempiere 1.0.

📄️Simplified GL Journal

Simplified GL Journal: a New Feature in iDempiere 1.0.

📄️GL Journal Generator

GL Journal Generator allows you to configure the generation of GL Journals based on previous journals movements.

📄️iDempiere workshop August 2014

There was a iDempiere workshop in August 2014 held by Carlos Ruiz (organized by Thomas Bayen)

📄️Info Window

Info Window: a New Feature in iDempiere 1.0.

📄️Improved Info Product

Improved Info Product: a New Feature in iDempiere 1.0.

📄️Inventory Documents

Inventory Documents: a New Feature in iDempiere 1.0.

📄️Manufacturing Light

Manufacturing Light: a New Feature in iDempiere 1.0.

📄️Map Route On Locations

Map Route On Locations: a New Feature in iDempiere 1.0.

📄️Mixed POS Payments on Sales Order

Sales Order window was modified to allow management of Mixed Payments on POS Orders, this is, a sales order that is paid with different tender types.

📄️Payment Batch

Main goal of this feature is to allow users to group payments in batches in order to reconcile several payments in one single statement line.

📄️Request Calendar Dashboard

The "Request Calendar" allows the user to create, view and query quickly any request.

📄️Reverse Accrual

Implement reverse accrual for shipment, invoice, inventory and payment document.

📄️Storage Improvements

Storage Improvements: a New Feature in iDempiere 1.0.

📄️Automatic List Refresh

When adding a new record on a table, the related lists don't need to be refreshed, the new record is automagically added to the list.

📄️Broadcast Message

Broadcast Message: a New Feature in iDempiere 1.0.

📄️Change Role

Change Role: a New Feature in iDempiere 1.0.

📄️Column Toolbar Buttons

Option to display column button as part of the window toolbar instead of in the form.

📄️Context Help Pane

Context Help Pane: a New Feature in iDempiere 1.0.

📄️Improved Form Layout

Improved Form Layout: a New Feature in iDempiere 1.0.

📄️Frequent lists

Frequent lists: a New Feature in iDempiere 1.0.

📄️ImportCSV

ImportCSV: a New Feature in iDempiere 1.0.

📄️Link End Process With Next Record

Now the output of some processes that create new documents or records in other tables allows the user to navigate directly to those new records

📄️Login Improvements

Now users can login directly using the defaults that used on their last session (client, role, organization, warehouse).

📄️Menu

Menu: a New Feature in iDempiere 1.0.

📄️New Master Detail Implementation

New master detail implementation to improve usability.

📄️Payment Field

The "payment method" field is now a list on Sales Order, Purchase Order, Customer Invoice and Vendor Invoice

📄️Configurable Quick Entry

Configurable Quick Entry: a New Feature in iDempiere 1.0.

📄️Recent Items Dashboard

Recent Items Dashboard: a New Feature in iDempiere 1.0.

📄️Report Button

Report Button: a New Feature in iDempiere 1.0.

📄️Report Wizard

Report Wizard: a New Feature in iDempiere 1.0.

📄️Configurable Grid Layout

Configurable Grid Layout: a New Feature in iDempiere 1.0.

📄️Setup Wizard

We want to extend the setup workflows to allow setting up more friendly setup wizards.

📄️Standardize OK Cancel Buttons

For usability is important to always see the OK and Cancel buttons in the same order.

📄️Tab Editor

The new button "Tab Editor" is a WYSIWYG application that enables you to see and edit how a tab is going to be displayed.

📄️User Feedback

Add user feedback menu to make it easier for user to create support request or contact support through email.

📄️Welcome Page

The welcome page has been redesigned to provide more configuration and better information to the user.

📄️Window Customization

Customize for user the columns to show and the order in the window on grid mode

📄️Active Login Session List

Active Login Session List: a New Feature in iDempiere 1.0.

📄️Base Language Flexible

Base Language Flexible: a New Feature in iDempiere 1.0.

Code Best Practices: a New Feature in iDempiere 1.0.

📄️Custom Window Toolbar Buttons

Create custom toolbar button for window using OSGi dynamic service.

📄️Distributed Cache

Distributed Cache: a New Feature in iDempiere 1.0.

📄️Scheduler Improvements

This feature enable to define a schedule that can be used in any of the scheduled processes.

📄️Storage Providers

Storage Providers: a New Feature in iDempiere 1.0.

📄️Translation Improvements

Translation Improvements: a New Feature in iDempiere 1.0.

📄️Web Services Improvements

Web Services Improvements: a New Feature in iDempiere 1.0.

📄️Window Tab Toolbar Buttons

You can now define new process/form toolbar button for a window tab without the need to create a dummy ad_column record.

📄️Forgot My Password

"Forgot My Password" provides the user the ability to retrieve your password.

📄️Hashed Passwords

The default plain passwords configured in vanilla iDempiere are very unsafe, access to the database will expose all passwords.

📄️Password Rules

Password Rules: a New Feature in iDempiere 1.0.

📄️Restrict Toolbar Buttons

You can now easily restrict a toolbar button for a specific role, or a role in a window, or even for all windows ( system administrator only).

📄️Improved Role Access Update

Improved Role Access Update: a New Feature in iDempiere 1.0.

Role Inheritance: a New Feature in iDempiere 1.0.
