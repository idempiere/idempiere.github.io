# Time Line Record Info

**Goal:** Usability

**Developer:** Heng Sin Low

**Description:**

Now iDempiere can show the Record Info (audit changes for a record) in Time Line view mode.  The usual Change Log mode is still the default, you can click on the Time Line radio button to see the new presentation:
