# Multi Warehouse Inventory Valuation Report

> **Developer:** Carlos Ruiz

**Goal:** Functional

**Description:**

Now the inventory valuation report can be executed for multiple warehouses, the parameter warehouse was changed to support multiple selection, when the parameter is left empty, all warehouses are reported.
