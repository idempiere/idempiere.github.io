Testing history

This page records how testing in iDempiere changed over time, so you can tell current practice from old advice. The facts come from the core Git history and the linked JIRA tickets.

Summary​

PeriodApproach
Before 2020Mostly manual. FitNesse and Selenium were tried, but few tests were written
2020 to 2024One JUnit 5 bundle on a real Garden World database becomes the standard
2025 onwardMockito, coverage measurement, more tests asked for in review, Playwright planned
